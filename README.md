
# BudgetBee – Small Savings, Bigger Goals

BudgetBee is a smart personal finance and budgeting system developed using C++17, Data Structures and Algorithms (DSA), HTML, CSS, and JavaScript.

## Features

- Financial summary and safe-to-spend calculation
- Transaction management
- Prefix-based transaction search using Trie
- Top-K expense extraction using Min-Heap
- Group expense settlement
- Savings goal optimization using 0/1 Knapsack
- Spending anomaly detection
- 7-day moving average analysis
- Category-wise and monthly expense summaries
- Local REST API server

## Technologies Used

- C++17
- HTML
- CSS
- JavaScript
- Data Structures and Algorithms

## DSA Concepts

- Trie – Transaction searching
- Min-Heap – Top-K expenses
- Graph – Group expense settlement
- Dynamic Programming – Savings optimization
- Sliding Window – Moving average
- Statistical analysis – Spending anomalies

## How to Compile and Run

Open the project folder in the terminal and execute:

```bash
g++ -std=c++17 git.cpp -o budgetbee
./budgetbee
```

## Project Structure

- `git.cpp` – C++ core engine
- `index.html` – Web interface
- `backend.cpp` – Backend implementation
- `output/` – Project output files
